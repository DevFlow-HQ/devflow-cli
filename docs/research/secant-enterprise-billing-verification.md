# Verify Enterprise and Actions billing for Secant

Checked 2026-10-07. Read-only checks; no subscription, trial, repository, workflow run, or budget was created or changed.

## Confirmed from current official documentation

- Enterprise Cloud advertises 50,000 included standard-runner minutes and 50 GiB of shared artifact/Packages storage monthly. These are account/enterprise allowances, not 50,000 minutes per seat. Team includes 3,000 minutes and 2 GiB. Public standard-runner work and self-hosted Actions remain free. Larger runners always cost extra. [Billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
- Enterprise's public list price starts at $21 per user/month for the first 12 months. It is not Team. Public pricing is not a binding account-specific quote and gives no guaranteed post-year-one price. [Pricing](https://github.com/pricing).
- New Enterprise trials created since August 1, 2024 use monthly usage-based licensing, based on the actual unique licenses consumed rather than a fixed prepaid seat commitment. Credit card, PayPal and Azure payment are supported. The documented example begins with zero licenses; the docs impose no annual volume agreement or published mandatory ten/fifty-seat floor for that model. Root also observed Secant's authenticated checkout offering one seat at $21 per month, with a minimum of one corresponding to the existing member. No purchase was submitted. [Usage-based licenses](https://docs.github.com/en/billing/concepts/enterprise-billing/usage-based-licenses), [enterprise bills](https://docs.github.com/en/billing/concepts/enterprise-billing/billing-for-enterprises).
- Organization owners and members consume licenses. Outside collaborators on private/internal repositories consume licenses; public-repository outside collaborators do not. Adding another private contributor would increase a one-seat $21 base price. [License users](https://docs.github.com/en/billing/reference/github-license-users).
- Actions Linux x64 costs $0.006/min, Windows x64 $0.010/min and macOS standard M1/Intel $0.062/min above allowance. Jobs round billable runtime up per job. The pricing calculator explicitly excludes included entitlements; using it cannot resolve quota accounting. [Runner billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions), [job execution time](https://docs.github.com/en/actions/how-tos/monitor-workflows/view-job-execution-time), [calculator FAQ](https://github.com/pricing/calculator?feature=actions).
- An Actions budget can stop metered use after included quota and a chosen paid budget are exhausted. Alert-only budgets do not stop spending. A zero-extra-spend cap protects overage but may stop CI, so it is not proof the workflow fits the allowance. [Budgets](https://docs.github.com/en/billing/how-tos/set-up-budgets).
- Native GitHub workflow logs and job summaries do not count towards artifact storage. Secant uploads its own operational JSONL logs through `actions/upload-artifact`; those do count as artifact storage, so the earlier report's operational-log warning remains correct. Cache storage has a separate 10 GiB/repository allowance. Shared artifact/Packages storage accrues hourly, and deleting an artifact only stops future accrual. [Storage billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions), [Secant check workflow](https://github.com/secantdev/secant/blob/main/.github/workflows/check.yml).

## Observed Secant account usage

Authenticated REST `GET /orgs/secantdev` returned plan `free` and one filled seat. This is an observation of today's organization, not a future Enterprise quote.

Root then inspected the signed-in billing page and its same-origin read-only response `GET /organizations/secantdev/settings/billing/discounts?month=10&year=2026&filter_included_usage=true`. The active Free plan's recurring included discount has `targetAmount: 12`, `currentAmount: 0`, and one shared set of six standard runner SKUs: `actions_linux`, `actions_macos`, `actions_windows`, `actions_linux_arm`, `actions_windows_arm` and `actions_linux_slim`. The returned discount is a fixed monetary amount. This directly establishes a $12 shared plan credit on the current account, matching 2,000 advertised minutes multiplied by the current Linux $0.006 rate. A separate $0.125 shared storage discount matches the Free 0.5 GiB allowance at $0.25/GiB-month. The public workflow has not consumed this plan credit. GitHub's frontend response is account-specific observed evidence, not a public REST contract.

The existing Actions paid budget is $0 with Stop usage enabled, observed in that signed-in UI. No pending plan change or active trial exists; the current plan remains Free.

The documented `GET /organizations/secantdev/settings/billing/usage/summary?year=2026&month=9&repository=secantdev/secant` returned a complete September summary. Detailed daily usage agrees with it. Linux used 1,933 minutes at $11.598 gross; macOS 1,565 at $97.03 gross; Windows 3,633 at $36.33 gross. Total is 7,131 reported minutes and $144.958 gross list-price runner value. All were discounted and net charges were $0. Storage was 13,245.720361083 GiB-hours at $4.450826727 gross, also fully discounted. September average storage was approximately 18.40 GiB. These are metering observations for public work, not a private invoice or a forecast for the current larger workflow. [Usage API](https://docs.github.com/en/rest/billing/usage#get-billing-usage-summary-for-an-organization).

October's partial-month API summary returned Linux 1,325 minutes, macOS 1,287 and Windows 1,981, total 4,593 reported minutes and $107.554 gross runner value; net charges are zero. Its Windows discount quantity exceeds gross quantity by 17 minutes, so discount quantity is not a reliable included-entitlement counter. The figures are provisional through the read time.

Raw account responses are local-only in `/tmp/secant-confirm-sept-usage-raw.json`, `/tmp/secant-confirm-sept-repo-usage-raw.json`, `/tmp/secant-confirm-sept-detail-raw.json` and `/tmp/secant-confirm-account-usage.json`. They contain account information and should not be committed as public evidence.

## What still cannot honestly be certified

**Enterprise's exact credit amount and whether all existing three-OS CI fits $21/month.** The active Free account now confirms a shared monetary runner allowance, so raw minutes and the old 1/2/10 weights should no longer be presented as equally plausible mechanisms for Secant's present plan. Applying the observed Linux-rate normalization to advertised Enterprise 50,000 minutes predicts a $300 monthly shared standard-runner credit, but this Enterprise credit itself has not been observed on Secant because it has not upgraded. The official announcement is consistent with this monetary mechanism and says usage consumes allowance based on list price. Current public documentation does not state the actual Enterprise dollar-credit amount. [Official announcement](https://github.blog/changelog/2025-12-16-coming-soon-simpler-pricing-and-a-better-experience-for-github-actions/), [intentional documentation patch](https://github.com/github/docs/commit/ce33310edb3d6ad3a43437b877a6f191c9349f0c).

The official docs issue was checked including its comments. Its closure is not an answer to quota conversion. The contributor says removal was not a mistake and directs the questioner to account support. The comment does not state the current conversion formula. [Maintainer reply](https://github.com/github/docs/issues/45138#issuecomment-5038519783).

A customer-facing guide in `dane-joh/github-actions` explicitly states that active Enterprise customers receive $300/month for standard runner SKUs. The same author's older Actions resources publish a `github.com` staff email for customer questions. This corroborates the predicted $300 figure, but the guide is in a personal repository and the profile exposes no independently verified employer/name; it is not treated as a binding official plan quotation. The current official documentation/blog searches did not independently state $300. [Guide's pricing section](https://github.com/dane-joh/github-actions/issues/1), [author's customer-contact resource](https://gist.github.com/dane-joh/c07faca5a33681c01ac7933d165f5fe7).

The present public source's fully discounted usage cannot show the actual private Enterprise allowance on that future plan. The remaining evidence is a first-party Enterprise $300 credit statement or the same read-only discount response after a separately authorized upgrade. A GitHub support reply could also settle it. No private workflow needs to run merely to inspect the plan's configured credit.

**Taxes and year-two renewal.** Secant's authenticated checkout now confirms one Enterprise seat on the monthly cadence at $21 base price. No annual prepayment or multi-seat minimum appeared. The maintainer confirms India and a personal purchase before GST business registration. No billing details were entered or saved, and the quote has no completed address, so the tax-inclusive charge is unconfirmed. Renewal behavior is established by the Terms of Service: the agreed price lasts for the payment term, prices can change at its end, and material price changes require 30 days notice. There is no guaranteed year-two price in those terms. [Payment and price-change terms](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#l-payment). The account remains Free and no upgrade or trial was activated.

**Private runner performance.** The public Linux/Windows standard machines have four vCPUs/16 GB; their private counterparts have two vCPUs/8 GB. The same job labels do not establish equal runtime after conversion. macOS M1 remains three vCPUs/7 GB. A complete private rehearsal is an implementation precondition, not a current measurement. [Hosted specs](https://docs.github.com/en/actions/reference/runners/github-hosted-runners).

Suggested exact support question, prepared only and not sent: Secant's current Free account's included-usage response shows a recurring fixed $12 credit shared across standard Actions SKUs, consistent with 2,000 Linux minutes at $0.006. Does a new one-user monthly Enterprise Cloud plan's advertised 50,000-minute allowance configure a $300 shared credit on the same SKUs? What are the first-year and renewal unit prices, and does the quote show applicable taxes before purchase?

## Complete recent job-runtime census

The bounded investigation script enumerates every check workflow run created between September 7 and October 6 inclusive, visits every run attempt, sums rounded per-job runtimes by runner OS and retains conclusions. It uses six concurrent bounded read-only requests. Its summarized output is [CI usage evidence](./secant-ci-usage-evidence.json). These public-runner timings supplement billing observations; they are not private quota accounting.

The census finished successfully: 500 distinct runs, 522 total attempts, Linux 3,157 rounded job-minutes, Windows 5,250, macOS 2,781. Total raw minutes are 11,188, and list-price value is $243.864. At the observed $0.006 Linux normalization this is 40,644 Linux-equivalent minutes. If Enterprise's configured credit is $300, the work would fit with $56.136, or 9,356 Linux-equivalent minutes, remaining. That is 18.7% of the assumed allowance. This replaces the earlier extrapolation of approximately 20,000 raw minutes/month. Reduced private Linux/Windows capacity can erase that margin. The old 1/2/10 scenario gives 41,467 minutes but should not be used as the present billing formula after observing the shared monetary credit.

Workflow job timings are deliberately retained per attempt to include reruns, cancelled and failed work. The census excludes skipped jobs and jobs without an assigned runner/completion timestamp. This is rounded wall-clock runtime inferred from job timestamps, not the metered billing quantity. The two should not be called interchangeable.
